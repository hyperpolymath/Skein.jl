Per-repo normative-scope record for Skein.jl (a standalone knot-database
library for Julia; see docs/decisions/ADR-0001 for the 2026-09-26 one-master

== Placement (re-grounded 2026-09-26, ADR-0001)

[literal]
consumers:  quandledb (storage + equivalence face; hosts krl)   tangle (separate language)
                │  consumes as a library                            │  no pipeline
                ▼                                                   ▼
            Skein.jl — standalone knot-database library (this repo)
                │  optional weakdep
                ▼
            KnotTheory.jl — computation toolkit (extension trigger)

The 2026-06-19 "computational/backend engine of the KRL stack" placement is
withdrawn: consumption defines neither purpose nor architecture
(INTEGRATION.adoc).

== Levels

* *MUST* — required to be what it is (RFC 2119 normative).
* *INTEND* — committed direction.
* *WISH* — aspirational.

== Skein.jl (own)

[cols="1,5", options="header"]
|===
| Level | Skein.jl

| *MUST*
| Be a *standalone, dependency-lean knot database* — store knots as Gauss
  codes (or canonical planar diagrams via the KnotTheory weakdep extension),
  auto-compute and index invariants (Jones, genus, Seifert circles) on insert,
  and answer invariant/equivalence queries (R1/R2, Jones comparison) over an
  embedded SQLite store; stay pure Julia (no ABI/FFI seam, no coprocessor
  backends — ADR-0001); SPDX/REUSE compliance on all files; the test suite
  green before any commit.

| *INTEND*
| Raise READINESS above `C`; strengthen the storage/schema obligations from
  *example/property-tested* toward proof where tractable (`PROOF-NEEDS.adoc`);
  keep KnotTheory.jl a *weakdep only* (never a hard dependency); register on
  the General registry (install by name, not url). Template debt cleared
  2026-09-26: the `{{PLACEHOLDER}}` files are filled and the accelerator
  extensions were removed as vestigial (Dustfile.a2ml), not matured.

| *WISH*
| Broader invariant coverage (e.g. Alexander polynomial standalone — *not*
  implemented; needs crossing-chirality data absent from basic Gauss codes);
  a re-grounded next schema version (the v5 knot-relation edge layer was
  *withdrawn* — mis-grounded on "KRL = query"; no committed next schema until
  re-grounded against Skein's own storage requirements); a measured, benchmarked
  fast path for bracket computation on large diagrams ◇.
|===

== Cross-repo wiring

Skein.jl is an *independent library* whose diagram-equivalence machinery
(`canonical_gauss`, `is_equivalent`, `find_equivalents`) is the part consumers
rely on most. *QuandleDB* wraps it as the persistence + invariant/equivalence
face of the KRL tooling; *KRL* is a resolution DSL implemented in QuandleDB;
*Tangle* is a separate knot-mathematics language with no compilation pipeline
to Skein. Consumption transfers no schema, purpose or proof guarantee.

Sibling repos' key concerns (consumer context, keep in sync as crossover
resolves): *krl* — the resolution DSL surface; *tangle* — TangleIR +
type-safe core; *quandledb* — equivalence / identity face (holds the canonical
QuandleDB/KRL crossover table); *echo-types* — structured-loss theory +
the identity-fabric framing. See `../../AFFIRMATION.adoc` and
`../../INTEGRATION.adoc`.
